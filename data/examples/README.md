# Tickform — Piccoli esempi selezionati

Solo piccoli dataset intenzionalmente selezionati per esempi, test e regression testing. Le regole Git consentono qui i `.raw`, anche in sottocartelle; i JSON non sono ignorati. Gitignore non misura la dimensione: controllare la selezione prima di aggiungere file. Acquisizioni lunghe fuori repository. Ogni dataset reale dovrà avere provenienza, condizioni, test ID e revisione hardware/firmware. Nessun dataset creato in M0.

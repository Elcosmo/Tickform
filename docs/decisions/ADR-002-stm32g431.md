# ADR-002 — STM32G431CBU6 / WeAct Core Board

Status: Accepted

Date: 2026-09-16

## Context

La V0 richiede acquisizione I2S, DMA, metrologia timer e collegamento al PC.

## Decision

Usare WeAct Studio STM32G431 Core Board con MCU previsto STM32G431CBU6.

## Alternatives considered

Nessuna valutazione comparativa di altre MCU/board è documentata nella specifica iniziale. Non riaprire la selezione in M0.

## Consequences

Verificare marcatura MCU, clock, SWD, USB, mapping e funzionamento delle periferiche nel bring-up. Nessun firmware reale o progetto CubeMX in M0.

# ADR-005 — Nessun display in V0

Status: Accepted

Date: 2026-09-16

## Context

Il PC è parte integrante della prima versione per acquisizione, visualizzazione e analisi.

## Decision

Nessun display locale in V0; usare il PC come interfaccia.

## Alternatives considered

Display integrato non adottato per V0. Non è documentata una decisione sulle interfacce di versioni successive.

## Consequences

GUI e analisi verranno affrontate dopo acquisizione RAW affidabile. Nessuna GUI in M0.

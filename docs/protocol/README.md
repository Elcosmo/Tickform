# Tickform — Documentazione protocollo

Spazio per la futura specifica del trasporto STM32 → PC, requisiti di continuità, errori e revisione del protocollo. USB e packet framing firmware non sono congelati in M0. Gli eventuali artefatti condivisi andranno in `protocol/`; il formato di registrazione è separato in `docs/data-format/RAW_FORMAT_V0_1.md`.
